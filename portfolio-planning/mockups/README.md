# Mockups (disposable)

These files are **design mockups for review at Gate 3**, not the website implementation. They live under `portfolio-planning/` so they never collide with the real site, and they will not be reused as production code.

- `home.html` Homepage, Direction A (The Specification)
- `case-export-erp.html` Case study 1, Export ERP
- `styles.css` Shared mockup stylesheet (tokens at the top mirror `design-system.md`)
- `screenshots/` Rendered at 1280 px and 390 px with the real typefaces

Fonts load from Google Fonts when opened in a browser. A fixed control at bottom right switches the accent between pen-ink blue (proposed) and oxide red (the Gate 2 value) so both can be judged.
